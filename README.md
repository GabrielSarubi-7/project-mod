# Etheris — Ecos do Infinito

Vertical slice inicial para Minecraft Java 1.21.1 com NeoForge.

## Estado atual

- Foco de Éter funcional: conjura **Faísca Astral**, consome Éter interior e aplica recarga.
- Éter interior persistente no jogador, com regeneração lenta.
- Coletor Etérico funcional: usa Fragmentos de Etherium para recarregar o foco.
- Quatro blocos da fundação do sistema registrados e disponíveis na aba Etheris.
- Assets visuais ainda são placeholders de desenvolvimento; a direção final depende do pipeline de arte/Blockbench.

## Execução

Use Java 21 e execute `gradlew runClient` para abrir o cliente de desenvolvimento. Para validar o build, execute `gradlew build`.

## Marcos

1. Fundação e primeiro loop jogável (esta branch).
2. Códice, descoberta da primeira ruína e oito magias do vertical slice.
3. Receitas e processamento real das quatro máquinas.
4. Rede de Éter, primeira estrutura multibloco e progressão I–III.
5. Conteúdo pós-MVP: lacaios, armaduras, dimensões e megamáquinas.
